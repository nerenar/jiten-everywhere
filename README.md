# Jiten Everywhere

A userscript that shows [Jiten](https://jiten.moe) stats such as character count, difficulty and coverage on [VNDB](https://vndb.org), [AniList](https://anilist.co), [MyAnimeList](https://myanimelist.net), [TMDB](https://www.themoviedb.org), [IMDb](https://www.imdb.com), [Letterboxd](https://letterboxd.com), [IGDB](https://www.igdb.com), [Syosetu](https://syosetu.com) and [Bookmeter](https://bookmeter.com). For works that aren't on Jiten yet, it opens Jiten's request form with the details filled in.

A Jiten API key is optional but recommended. It adds your own stats (coverage, progress, unknown words), lets you set your Jiten status from the page, checks for existing requests, and raises the rate limit. Sentence coverage also needs Jiten+.

Stats can be turned on or off and reordered, each site can show the stats in the page, in the bottom right or not at all, and titles can be shown in Romaji (the default, as on Jiten), Japanese or English.

## Install

1. Install [Violentmonkey](https://violentmonkey.github.io/), [Tampermonkey](https://www.tampermonkey.net/) or [Greasemonkey](https://www.greasespot.net/).
2. Install the script from [Greasy Fork](https://greasyfork.org/en/scripts/600904-jiten-everywhere).
